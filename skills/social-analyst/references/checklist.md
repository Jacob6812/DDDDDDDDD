# Sentiment Analyst Checklist

- State the current sentiment level: bullish / bearish / neutral.
- State the recent direction of sentiment: rising / falling / flat.
- Check whether price has ALREADY moved in line with the sentiment (crowding).
- Judge extremity: is consensus one-sided (contrarian edge) or mixed (no edge)?
- Apply the contrarian rule: euphoria-after-runup = fade; capitulation-after-drop = buy.
- Weight the CHANGE in sentiment above the absolute level.
- Set confidence from how extreme + well-evidenced the read is, not from how loud the crowd is.
